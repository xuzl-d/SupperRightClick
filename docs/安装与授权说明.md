# 超级右键（SuperRightClick）安装与授权说明

> 这份说明是写给**收到安装包的人**的。这个 App 没有 Apple 开发者签名，所以 macOS 会拦几次，
> 按下面步骤操作即可正常使用。全程大约 2 分钟。

---

## 一、系统要求

| 项目 | 要求 |
|---|---|
| 芯片 | Apple Silicon（M1 及以后）**或 Intel** —— 安装包是通用二进制，两种都支持 |
| 系统 | macOS 13.0（Ventura）或更高 |
| 权限 | 需要管理员密码（安装到「应用程序」） |

---

## 二、安装（会有一次拦截）

1. 双击 `SuperRightClick-1.1.0.pkg`。
2. 如果提示 **“无法打开，因为来自身份不明的开发者”**（或"Apple 无法检查其是否包含恶意软件"）：
   - 不要点「移到废纸篓」；
   - 打开 **系统设置 → 隐私与安全性**，向下滚动找到关于 `SuperRightClick-1.1.0.pkg` 的提示，
     点 **“仍要打开”**，再确认一次；
   - 然后重新双击 pkg。
   *(macOS 15 以后，“右键 → 打开”这个老办法对安装包不再总是有效，请用上面这个入口。)*
3. 按安装器提示输入**管理员密码**，完成安装。
4. 安装脚本会自动关闭正在运行的旧版本，并启动新版。菜单栏会出现 **“超级右键”** 图标。

> 安装包只做两件事：把 App 复制到 `/Applications`，然后启动它。没有其他系统改动。

---

## 三、首次启动（可能再拦一次）

如果 App 启动时提示 **“无法验证开发者”**：

**系统设置 → 隐私与安全性 → “仍要打开” → 输入密码 → 再次打开。**

放行一次之后，以后每次启动都不会再问。

**更省事的替代办法**（如果你熟悉终端）：安装完成后执行一次

```bash
sudo xattr -dr com.apple.quarantine /Applications/SuperRightClick.app
```

再启动就不会被拦。两个方法任选其一，第 2 种更快。

---

## 四、必须手动授权（关键，不授权就等于没装）

这个 App 的原理是**拦截访达里的右键事件**，所以前两个权限必须拿到；第三个只有用截图时才需要。**每台机器、每个用户都要各自授权，无法由别人代劳。**

### 1. 辅助功能（必需）

打开 **系统设置 → 隐私与安全性 → 辅助功能**，把 **超级右键** 打开。

- 不授权的表现：**右键毫无反应**，还是系统原生菜单。
- App 首次启动会自动弹出引导并把应用注册进这个列表，直接在列表里打勾即可。
- 如果列表里找不到它：在列表下方点 `+`，选择 `/Applications/SuperRightClick.app`。

### 2. 输入监控（部分系统版本需要）

打开 **系统设置 → 隐私与安全性 → 输入监控**，把 **超级右键** 打开。

- 拦截全局右键在底层属于「监听输入事件」，**部分 macOS 版本（尤其较新的版本）会额外要求这一项**。
  如果辅助功能已经勾选、但右键仍然没有任何反应，请务必检查这里。
- App 主界面会单独显示这一项的状态；点「重新检测」时会自动触发一次授权请求。
- 改动这一项后**需要退出并重新打开 App**。

### 3. 自动化 → 访达（首次使用时弹窗）

第一次对文件右键时，系统会问 **“超级右键”想要控制“访达”**，请点 **好**。

- 拒绝的表现：菜单能弹出，但读不到你选中的文件（“打开方式”“复制路径”等会失效）。
- 若当时点了「不允许」，去 **系统设置 → 隐私与安全性 → 自动化 → 超级右键 → 访达** 重新勾上。

### 4. 屏幕录制（只有用「截图」才需要）

第一次用右键菜单里的 **截图** 时，App 会提示并触发系统弹窗。
请到 **系统设置 → 隐私与安全性 → 屏幕录制**，勾选 **超级右键**，
**然后退出并重新打开本 App**（这项权限必须重启进程才生效）。

- 不授权的表现：截图出来的图**只有桌面壁纸**，窗口内容全是空的。
- 不装/不用截图功能的话，这一项可以完全不管。

### 为什么需要这些权限？

- **辅助功能**：读取鼠标右键事件，用来替换访达的原生右键菜单（这是唯一能实现该功能的系统接口）。
- **自动化**：通过 AppleScript 询问访达“当前选中了哪些文件”。
- **屏幕录制**：调用系统 `screencapture` 截屏（macOS 10.15 起截图必须由已授权的 App 发起）。

App **不联网、不收集任何数据、不上传文件**。截图只保存在你指定的本地文件夹或剪贴板里。
菜单里的每个动作都是在你本机执行的本地操作。

## 五、安装后自检

三条命令，全部通过就说明装好了：

```bash
# 1) 签名有效
codesign --verify --verbose=1 /Applications/SuperRightClick.app

# 2) 版本应为 1.1.0
/usr/libexec/PlistBuddy -c "Print :CFBundleShortVersionString" \
  /Applications/SuperRightClick.app/Contents/Info.plist

# 3) 架构应为 arm64 + x86_64
lipo -archs /Applications/SuperRightClick.app/Contents/MacOS/SuperRightClick
```

## 六、右键没反应？按这个顺序查（三步定位）

先分清是**哪一种**没反应，两者的原因完全不同：

| 现象 | 含义 | 跳到 |
|---|---|---|
| A. 出现的是**系统原生**菜单 | 我们没能拦截右键（权限或识别问题） | 第 1 步 |
| B. **什么菜单都不出现** | 右键被吞掉了，但自定义菜单没弹出来 | 第 3 步 |

**第 1 步：看 App 自己的状态面板**

点菜单栏「超级右键」图标 → **打开主界面**，看三行状态：

- `辅助功能权限：❌ 未授权` → 去「系统设置 → 隐私与安全性 → **辅助功能**」勾选**超级右键**，再点「重新检测」。
- `辅助功能权限：✅` 但 `右键拦截：❌ 未启动` → 再检查「隐私与安全性 → **输入监控**」是否也勾选了本应用
  （新版 macOS 会把这一项也纳入要求）。两项都勾上后点「重新检测」；仍不行走第 3 步。
- 三行都 ✅ → 说明拦截已就绪，问题在识别或弹菜单环节，走第 2 步。

**第 2 步：确认是不是「在非访达的地方右键」**

本 App 只替换**访达窗口内**和**桌面**的右键菜单，其它 App 里保持系统原生菜单。
另外若是**桌面**右键不生效，但**访达窗口内**正常，请把这一点告诉开发者。

**第 3 步：生成诊断报告发回来（最有效）**

菜单栏「超级右键」图标 → **生成诊断报告**。
它会在**桌面**生成 `超级右键-诊断报告.txt`（同时复制到剪贴板），内容包含：

- App 版本 / 路径 / 架构，macOS 版本与芯片
- 辅助功能、输入监控两项权限的**实际**状态
- 事件拦截是否创建成功、是否被系统降级到会话层、是否被停用
- 光标下最上层窗口的归属（判断访达识别是否正常）
- 运行日志尾部 40 行 + 是否有崩溃报告

把这份 txt 直接发给开发者即可，不用再猜。

> 也可以手动执行 `tail -40 /tmp/superrightclick.log` 看日志。日志里这几行分别对应：
> `事件拦截创建失败…`（权限/系统不允许）→ `右键目标非访达，放行给系统：…`（识别问题，后面会带是哪个进程挡住了）
> → `右键抬起: 触发自定义菜单`（已拦到）→ `准备弹出自定义菜单` → `自定义菜单已弹出`（成功）。
> **卡在哪一行，问题就在那一步。**

## 七、常见问题

**右键还是系统原生菜单，完全没反应**
→ 先看第六节三步定位。最常见的是辅助功能没授权，或授权后没有重新启动 App。

**菜单能弹，但「打开方式」里一直显示“加载中…”**
→ 你运行的是 **1.0.2 或更早**的版本。1.0.3 已改为同步枚举，不会再出现这个提示。
请确认版本号（第五节第 2 条），必要时重新安装。

**「复制路径」「打开方式」读不到我选中的文件**
→ 自动化权限被拒，见第四节第 3 条。

**截图存下来的图是空的（只有桌面壁纸）**
→ 「屏幕录制」权限没授权，见第四节第 4 条。**授权后必须退出并重新打开 App** 才生效。

**截图存到哪了？**
→ 存到**你右键点击的那个文件夹**（在文件上右键则存到它所在文件夹），文件名形如
`截图 2026-10-01 20.15.30.png`，存好后会自动在访达里选中它。
只想放进剪贴板的话，用子菜单下半部分的三个「…到剪贴板」，然后直接 `⌘V` 粘贴。

**启动时提示「此版本包含一个与 macOS 后续版本不兼容的组件」**
→ 这是 **Apple 从 macOS 26 开始的「Intel 架构 App 支持终止」提醒**，不是报错、更不是病毒。
当安装的是**通用包**（`…-universal.pkg`，为兼容 Intel Mac 而同时含有 x86_64 切片）时，
Apple 芯片机器每次启动都会提示一次。

- 如果你是 **Apple 芯片**机器：换用**不含 `-universal` 后缀**的安装包（只含 arm64），提示即消失。
- 如果你是 **Intel** 机器：这个包你需要它，提示只是 Apple 在预告未来 macOS 不再支持 Intel，
  功能完全不受影响，可以忽略。

**安装完在「应用程序」里找不到**
→ 这台机器别处（如 `~/Applications`）已有一份同标识的 App，安装被重定位到了那里。
用 `mdfind -name SuperRightClick.app` 找一下实际位置。

**想彻底卸载**

```bash
# 1) 退出 App（菜单栏图标 → 退出），并关掉开机自启动开关
# 2) 删除 App
sudo rm -rf /Applications/SuperRightClick.app
# 3) 可选：清掉权限记录
tccutil reset Accessibility com.superrightclick.app
tccutil reset AppleEvents com.superrightclick.app
tccutil reset ScreenCapture com.superrightclick.app
```

**排障日志**：App 会把运行日志写到 `/tmp/superrightclick.log`（含右键拦截、枚举耗时等信息）。
反馈问题时附上它尾部几十行即可，例如 `tail -30 /tmp/superrightclick.log`。
注意该文件是明文日志，不含你的文件内容。

## 八、已知限制

- 右键替换**只在访达和桌面生效**，其他 App 里保持系统原生菜单。
- 新建文件模板支持 txt / md / json / csv / rtf / docx / xlsx；暂不支持 pptx / pages / key / numbers。
- 没有 Apple 开发者签名与公证，所以首次安装和启动各需要手动放行一次（见第二、三节）。
- 开机自启动需要在 App 主窗口里手动开启，可能还要在
  **系统设置 → 通用 → 登录项** 里批准一次。
