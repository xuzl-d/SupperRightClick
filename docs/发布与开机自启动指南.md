# 发布与开机自启动指南

## 1. 开机自启动（已内置）

主窗口提供「开机自启动」勾选框，基于 `SMAppService.mainApp`（macOS 13+ 官方 API），
写入系统「登录项」：

- **勾选** → `SMAppService.mainApp.register()`，出现在「系统设置 → 通用 → 登录项与扩展」
- **取消勾选** → `unregister()`

注意事项：

1. **App 位置**：注册的是 App 当前路径。请把 `SuperRightClick.app` 移到 `/Applications`
   后再勾选；移动后如登录项失效，重新勾选一次即可。
2. **签名身份**：登录项绑定代码签名身份。本项目用稳定自签名证书（见下文），
   本地使用不受影响；正式发布换 Developer ID 签名后需重新勾选一次。
3. macOS 14.4+ 首次注册可能显示「在登录时打开」需用户允许（系统设置里点允许）。

## 2. 发布路线对比

| 路线 | 要求 | 适合 | 限制 |
|---|---|---|---|
| **A. Developer ID 官网分发**（推荐） | Apple Developer 账号（$99/年） | 独立工具类 App（iRightMouse 免费版走此路线） | 需签名 + 公证 + 自建下载/更新 |
| **B. Mac App Store** | 同上 + 审核 | 触达付费用户 | 必须沙盒；文件操作能力受限，需大量改造 |
| **C. GitHub/开源 + Homebrew** | 免费 | 开源社区版 | 用户需自行信任（右键打开绕过 Gatekeeper） |

推荐先走 A（官网分发），稳定后再评估 B。

## 3. 路线 A：Developer ID 签名 + 公证 + DMG

### 3.1 一次性准备

1. 注册 [Apple Developer Program](https://developer.apple.com/programs/)（$99/年）
2. Xcode → Settings → Accounts → 添加账号 → 下载证书
3. 在 [developer.apple.com/account](https://developer.apple.com/account) → Certificates 创建
   **Developer ID Application** 证书（本地钥匙串会得到身份 `Developer ID Application: Your Name (TEAMID)`）

### 3.2 签名

```bash
IDENTITY="Developer ID Application: Your Name (TEAMID)"
codesign --force --options runtime --timestamp --sign "$IDENTITY" dist/SuperRightClick.app
```

> `--options runtime`（Hardened Runtime）是公证的硬性要求。

### 3.3 公证（notarization）

```bash
# 1. 打包 zip（公证只接受 zip/dmg/pkg）
ditto -c -k --keepParent dist/SuperRightClick.app dist/SuperRightClick.zip

# 2. 提交公证
xcrun notarytool submit dist/SuperRightClick.zip \
  --apple-id "you@example.com" --team-id "TEAMID" --password "app-specific-password" --wait

# 3. 装订票据（务必执行，否则离线无法验证）
xcrun stapler staple dist/SuperRightClick.app

# 4. 验证
spctl --assess --type execute -vv dist/SuperRightClick.app   # 应输出 accepted
```

App 专用密码在 appleid.apple.com → 登录与安全 → App 专用密码 创建。

### 3.4 制作 DMG

```bash
mkdir -p dmg-root
cp -R dist/SuperRightClick.app dmg-root/
ln -s /Applications dmg-root/Applications   # 拖拽安装

hdiutil create -volname "超级右键" -srcfolder dmg-root -ov -format UDZO dist/SuperRightClick.dmg
codesign --sign "$IDENTITY" dist/SuperRightClick.dmg   # DMG 本身也建议签名
```

### 3.5 自动更新（可选）

- [Sparkle 2](https://sparkle-project.org/)：App 内更新框架（免费开源），配 appcast.xml
- 或走 Homebrew Cask / `softwareupdate` 不适用
- MVP 可先做「检查更新」菜单项（访问 GitHub Releases API）

### 3.6 PKG 安装包（一键自动安装到 /Applications）

```bash
./scripts/build-pkg.sh 1.0.0
# 产物: dist/SuperRightClick-1.0.0.pkg
# 双击 → 输入管理员密码 → 自动装到 /Applications，并自动启动新版
```

已包含 postinstall（关闭旧实例 + 以当前用户会话启动新版）。
正式分发时用 **Developer ID Installer** 证书给 pkg 签名：

```bash
productsign --sign "Developer ID Installer: Your Name (TEAMID)" \
  dist/SuperRightClick-1.0.0.pkg dist/SuperRightClick-1.0.0-signed.pkg
```

### 3.6 发布渠道

- 官网 + 下载页（DMG + 版本历史 + 使用说明）
- GitHub Releases（附带开源/社区版）
- 分发时注意：辅助功能权限引导页是转化关键，主窗口已有权限向导

## 4. 路线 B：App Store 需要的改造点

1. **沙盒**：开启 App Sandbox entitlement
2. **文件操作**：所有写入改为 `NSOpenPanel` 授权的 security-scoped bookmark（新建文件、压缩、删除等），
   或全部经 Finder AppleScript 执行（Finder 进程持有权限）
3. **Finder Sync Extension** 可作为沙盒友好的官方注入补充
4. CGEventTap 在沙盒内可用（辅助功能授权不变）
5. 审核重点：菜单替换行为、权限说明文案（NSAppleEventsUsageDescription 已配置）

## 6. 一键脚本占位（拿到证书后）

`scripts/release.sh`（示例骨架）：

```bash
#!/bin/bash
set -euo pipefail
./scripts/build-app.sh release
source .release-env   # IDENTITY / APPLE_ID / TEAM_ID / NOTARY_PASSWORD
codesign --force --options runtime --timestamp --sign "$IDENTITY" dist/SuperRightClick.app
ditto -c -k --keepParent dist/SuperRightClick.app dist/SuperRightClick.zip
xcrun notarytool submit dist/SuperRightClick.zip --apple-id "$APPLE_ID" --team-id "$TEAM_ID" --password "$NOTARY_PASSWORD" --wait
xcrun stapler staple dist/SuperRightClick.app
mkdir -p dmg-root && cp -R dist/SuperRightClick.app dmg-root/ && ln -sf /Applications dmg-root/Applications
hdiutil create -volname "超级右键" -srcfolder dmg-root -ov -format UDZO dist/SuperRightClick.dmg
echo "发布产物: dist/SuperRightClick.dmg"
```
